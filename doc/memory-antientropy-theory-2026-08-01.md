# 新鲜事实驱动的记忆反熵

## 一种面向长期记忆的近因、证据与可逆收敛机制

> **状态**: Draft
>
> **定位**: 可独立阅读的理论与设计框架，不绑定任何产品、模型或存储引擎。
>
> **实现关系**: 任意能够在新事实进入时发现、裁决并迁移旧事实的系统，都可以是本框架的一个实现。`hindsight-memorial` 是其中一个保守实现：它目前只处理明确的 `supersession`，不声称实现本文全部能力。

## 摘要

长期记忆系统的主要失效形式往往不是遗忘，而是失效信息仍被当作当前事实召回：同一现实有多种表述，旧状态与新状态同时活跃，事实之间的依赖关系随演化而断裂。本文提出**新鲜事实驱动的记忆反熵**（Memory Anti-Entropy）框架：将每次新事实写入视为一次针对既有活跃记忆的裁决机会；在严格的时间、来源、实体和上下文边界内，检索可能受影响的旧断言，判断其与新断言的关系，并将结论以可审计、可逆的方式投影到活跃记忆集。

本文的核心不是“新的一定正确”，而是一个受约束的更新规则：**对于描述同一对象、同一属性、同一适用上下文的当前状态断言，更近且更可信的观测拥有更高的当前状态解释权。** 系统默认偏向不行动，所有迁移保留证据链，并把不确定的冲突显式留在待审状态。

“反熵”在本文中是一个操作性名称：系统持续降低活跃记忆中与当前任务有关的矛盾、冗余和陈旧暴露，而不是声称对原始文本的 Shannon entropy 或热力学熵做直接计算。

**关键词**: 长期记忆、时态事实、事实溯源、软失效、冲突裁决、可逆性、记忆治理

---

## 1. 问题：长期记忆中的失配累积

持续写入的记忆系统会自然积累三类失配：

1. **表述冗余**：同一事实被不同措辞、不同粒度反复记录；
2. **状态冲突**：现实已经改变，旧状态仍处于可召回的活跃集合；
3. **关系断裂**：一个事实被更正后，依赖它的解释、偏好或派生结论仍指向旧前提。

因此，长期记忆的核心问题通常不是“信息丢失”，而是**活跃记忆投影与当前现实之间的失配**。存档中保留丰富历史并非问题；问题在于召回路径无法区分“当时为真”与“现在仍有效”。

记忆反熵关注的对象不是删除历史，而是维护一个可靠的**当前投影**（active projection）：在需要回答“现在是什么”的场景中，系统应优先返回仍适用、证据可追溯的断言。

## 2. 范围与基本对象

### 2.1 两种不可混淆的事实

- **状态事实（state fact）**：描述某一对象在特定时间、上下文下“当前是什么”。例如“服务监听端口为 9602”“用户当前偏好简洁回答”。它会因现实变化而失效。
- **事件事实（event fact）**：描述“曾发生过什么”。例如“服务于 2026-08-01 迁移到端口 9602”。它锚定过去，不会因后续状态改变而被覆盖，只可能被补充、纠错或重新解释。

近因性只适用于状态事实。将状态更新机制用于事件事实，会把历史保真错误地当作历史清理。

### 2.2 事实断言

本文以“事实断言”而非原始文本作为裁决单位。一个可裁决的断言至少应能表达：

```text
assertion = {
  subject,            # 描述对象
  predicate,          # 属性、关系或命题
  value,              # 取值或命题内容
  context,            # 作用域：项目、环境、角色、条件等
  valid_time,         # 该断言在现实中适用的时间或区间
  recorded_at,        # 系统收到或写入它的时间
  provenance,         # 来源、证据和提取路径
  confidence,         # 结构化或可解释的置信信息
  lifecycle_state     # pending / active / superseded / disputed / archived
}
```

自然语言记忆不必在写入时完全结构化，但裁决器至少需要推断这组字段中的 `subject`、`predicate`、`context` 与时间信息。没有可比性，就不应执行覆盖判断。

### 2.3 有效时间与记录时间

`valid_time` 表示事实在现实中何时成立；`recorded_at` 表示系统何时获知它。二者不能互换。一个迟到的、但明确描述昨天的事件，不应因为刚写入就覆盖今天的状态；一条今天记录的猜测，也不应自动压过较早但来源明确的确认信息。

## 3. 近因性：受约束的当前状态更新规则

近因性不是“新 = 正确”，也不是无条件的 Last-Write-Wins。它只在候选断言满足以下前提时提供一个**优先级信号**：

1. 二者都是状态事实；
2. 二者描述同一 `subject + predicate`，或存在被明确定义的语义等价关系；
3. 二者的 `context` 可比较，且适用范围重叠；
4. 新断言的 `valid_time` 更晚，或其更正意图与证据足以支持更新；
5. 新断言的来源质量、权限或置信度没有低到应被拒绝参与裁决。

在这些前提成立后，更近的有效观测通常更适合解释当前世界状态。时间只是证据维度之一；来源权威性、直接性、明确性和上下文匹配同样构成优先级。实际系统可用评分或规则表达这一偏序，但不应把单一时间戳伪装成真值判定器。

这一规则允许后续观测修正先前错误，也允许人工确认、权威数据或高置信传感器拒绝低质量的新输入。它追求的是可持续纠错，而非一次裁决的绝对正确。

## 4. 反熵循环

一次反熵循环由新断言触发。它改变的是活跃投影，而不是历史记录本身。

### 4.1 准入：先进入待裁决态

新断言进入系统后应先处于 `pending`。在异步实现中，这意味着系统只能承诺**最终收敛**：裁决完成前，召回层应能识别或过滤未决断言，避免把新旧冲突同时当作已确认的当前事实。

### 4.2 候选检索：先缩小可比集合

系统依据实体、谓词、上下文、时间窗口、显式关系和语义检索，得到候选集合 `C`。向量相似度只适合召回候选，不足以证明两条断言可以互相覆盖。候选阶段的目标是高召回；执行迁移前仍需满足严格的可比性门槛。

### 4.3 裁决：给出关系，而不只给出动作

裁决器对新断言与候选集合判断下列关系之一：

| 关系 | 含义 | 活跃投影动作 |
| --- | --- | --- |
| 等价 | 同一断言的重复表述 | 合并引用或标记冗余，不产生新的当前状态 |
| 细化 | 新断言补充旧断言的缺失维度 | 两者保留，并建立补充关系 |
| 覆盖 | 新断言整体替代旧状态 | 旧断言软失效，并指向新断言 |
| 矛盾 | 可比字段取值冲突，但证据不足以判断谁应生效 | 保留双方，标记 `disputed` 或请求复核 |
| 无关 | 语义相近但不描述同一可比状态 | 不改变彼此状态 |

裁决结果必须包含断言 ID、关系类型、依据摘要、使用的证据、裁决器版本与时间。对于多对多冲突，裁决单位应是断言集合或约束集合，而非把所有关系强行拆成独立的两两判断。

### 4.4 迁移：改变投影，保留历史

覆盖或被确认的矛盾不会删除旧断言，而是把其生命周期迁移为 `superseded`，并建立演化边：

```text
old assertion --superseded_by--> new assertion
                 reason / evidence / decided_at
```

这条边是可追溯性的最小单位。它使系统能够回答“为什么不再召回旧信息”“它何时失效”“由哪条新证据取代”，也为恢复、审计和离线评估提供基础。

## 5. 安全原则：存疑不杀

裁决器会发生两类错误：

- **漏判**：应迁移的旧断言仍活跃，导致冗余或过期暴露；
- **误判**：仍有效的断言被移出活跃投影，导致召回缺失或错误行动。

二者成本不对称。误判通常更危险，因此默认策略应是：

1. 只软失效，不硬删除；
2. 先持久化裁决证据，再改变活跃状态；
3. 低置信、跨上下文、来源不明或集合级冲突默认不自动迁移；
4. 为高风险谓词设置更高门槛或人工复核；
5. 支持恢复旧断言，并把恢复本身作为新的裁决事件记录。

这不是实现上的保守妥协，而是该机制成立的条件。没有可逆性与审计，错误裁决会让系统以不可见的方式损失知识。

## 6. 系统性质与成立条件

### 6.1 概率性收敛

在持续出现相关新观测、候选检索覆盖充分、裁决质量稳定且写入不会无限制造等价新表述的条件下，同一状态主题的活跃断言会趋向较少、较一致的表述。

这不是无条件保证。若输入持续矛盾、来源不可靠、裁决器不稳定，或不同上下文被错误混合，系统可能振荡、分裂或错误收敛。因而“收敛”应始终表述为可测量、可回归测试的经验性质，而不是由 LLM 自动获得的定理。

### 6.2 可追溯性

任一非活跃断言应能定位到：原始内容、来源、生命周期变更、对应裁决、证据摘要和替代链。事件溯源能提供记录结构，但不会自动提供正确的语义裁决；两者缺一不可。

### 6.3 两级可逆性

- **数据可逆**：原始断言和裁决证据仍可读取；
- **投影可逆**：旧断言可在新的反证或人工确认后重新进入活跃投影。

前者是最小承诺，后者是增强能力。自动重新激活必须同样经过可审计的裁决，不能把“撤销最近一次操作”误当作恢复现实状态。

### 6.4 幂等性与顺序性

同一新断言的重复投递不应产生重复迁移；同一候选集合在相同输入和策略版本下应获得稳定结果。分布式或异步实现还必须显式处理乱序、迟到事件与并发裁决，不能只依赖本地写入顺序。

## 7. 如何度量“更有序”

“反熵”必须能被观测，而不是停留在叙事。以下指标可按主题、时间窗和任务类型分别计算：

| 指标 | 示例定义 | 期待变化 |
| --- | --- | --- |
| 活跃冲突率 | 违反同一状态约束的活跃断言对 / 可比断言对 | 下降 |
| 活跃冗余率 | 被判定为等价的活跃断言数 / 活跃断言数 | 下降 |
| 陈旧暴露率 | 在带时间基准的评测中，召回结果含已失效断言的比例 | 下降 |
| 裁决精确率 | 自动迁移中，经人工或可信基准确认正确的比例 | 上升或维持高位 |
| 裁决召回率 | 应迁移断言中实际被发现并迁移的比例 | 上升 |
| 证据完整率 | 具备原文、来源、理由、时间和替代边的迁移记录比例 | 接近 100% |
| 恢复成功率 | 被误迁移后可恢复且恢复后召回正确的比例 | 上升 |

任何部署应同时报告精确率和召回率。只报告“清理了多少记忆”没有意义，甚至可能掩盖激进误杀。

## 8. “反熵”的信息论位置

本文不把原始记忆文本的 Shannon entropy 当作唯一目标函数。重复文本可能降低字面熵，却仍增加检索负担；相互矛盾的断言也不必然对应一个可直接计算的香农熵增量。

“反熵”在这里表达的是一种**状态估计整序过程**：系统维护关于当前世界状态的工作假设，新观测改变这些假设的相对可信度，裁决将不再适用的断言移出当前投影。若采用概率模型，可将其理解为带有时间衰减、来源权重和上下文约束的后验更新；若采用规则系统，则可理解为带有证据记录的真值维护。

热力学语言只承担直觉用途：系统需要持续输入新观测与计算资源，才能避免活跃投影自然陈旧。它不构成物理学上的熵减主张。

## 9. 与相关方法的关系

| 方法 | 提供的能力 | 本框架额外要求 |
| --- | --- | --- |
| Event Sourcing | 历史事件与可重放状态 | 将语义裁决及其证据建模为一等事件 |
| Temporal Database | 有效时间、记录时间与历史查询 | 根据语义关系维护当前投影 |
| Last-Write-Wins | 对并发写入的确定性取胜规则 | 允许时间以外的来源、上下文和证据参与裁决 |
| Truth Maintenance System | 信念依赖与撤销传播 | 把自然语言断言、时态证据和召回需求纳入处理 |
| 去重 / 摘要 | 降低表述数量 | 区分“语言相似”与“现实状态被覆盖” |

认知科学中的记忆重整合可作为启发性类比：记忆在被重新唤起时可能被更新。但它不构成对本框架有效性的实证背书，也不能替代工程上的评测与安全控制。

## 10. 最小实现契约

一个符合本框架最小要求的实现应具备：

1. 可区分状态事实与事件事实，或在不确定时拒绝自动覆盖；
2. 为断言保存来源、时间、上下文和生命周期状态；
3. 将新输入先作为待裁决候选，而不是无条件发布为当前真相；
4. 仅对满足可比性门槛的候选执行语义裁决；
5. 以软失效和显式演化边替代不可逆删除；
6. 将裁决理由、证据和策略版本持久化；
7. 在召回路径中优先使用 active projection，并支持审计与恢复；
8. 使用带时间基准的评测，报告误判与漏判，而不只报告清理数量。

一个只会“新写入覆盖旧写入”的系统不自动满足这些条件；一个保存所有历史但没有当前投影的系统也不满足。

## 11. 开放问题

1. **多值状态与上下文分裂**：同一属性可在不同环境、角色或时间段同时为真，如何避免错误地压成单值？
2. **集合级裁决**：多条新证据共同推翻一条旧结论，或一条新证据影响一组依赖结论时，如何定义最小且可解释的动作？
3. **关系迁移**：旧断言被迁移后，其派生结论、引用和索引应如何更新与回滚？
4. **来源与对抗输入**：如何量化来源可信度，防止新鲜但恶意或低质量的输入污染当前投影？
5. **冷区陈旧**：从未被新事实触发的主题如何进入审查，而不把周期扫描变成无证据的批量清理？
6. **隐私与保留**：软失效保留证据有助于审计，但也提高敏感信息的留存成本；保留策略需要独立治理。

## 12. 结论

记忆反熵不是“自动删除旧记忆”，而是把写入升级为一项受约束的、可审计的当前状态更新：新事实进入后，系统在可比范围内检查它改变了什么；证据充分时迁移旧投影，证据不足时保留分歧；无论结果如何，历史与理由都可被追溯和纠正。

> **记忆反熵 = 让每次可信的新状态观测，都有机会减少活跃记忆与当前现实之间的失配，同时不牺牲历史、证据与恢复能力。**
